Game sound effects your AI agent can actually design

Ask an AI for a coin sound and you get a raw beep that clicks, hisses and lasts too long. It can't hear, so it can't tell. game-sfx gives it ears: loudness metrics and spectrograms it can read.

/plugin marketplace add GhazaGG/Game-Sound-Effect-for-Claude

Then run /plugin install game-sfx@game-sfx. Pure Python stdlib, no API key, works offline.

WHAT AN AGENT USUALLY WRITES
0.0s

Clipped at 0 dBFS, clicks at start and end, flat, no transient. Half a second of buzz.

WITH GAME-SFX
0.0s

A two-note FM bell that rings out and decays to silence. -16 LUFS, no clicks, no harsh highs.

Recipes

Every sound is a small JSON patch you can edit. Click a waveform to seek.

How it works

Claude renders, looks at the doctor report, fixes, and repeats until it passes.

Click-proof synthBand-limited oscillators, envelopes that always end at zero, DC removal and LUFS-matched loudness.
DoctorPeak, LUFS, crest, brightness and aliasing checks, plus a spectrogram PNG Claude reads to check its own work.
CC0 foley pipelineFinds free recordings on Freesound, cuts the cleanest hits, layers impact, texture and a small room.
It learns your gameDetects your engine, reads your project and writes a sound bible so every sound feels like one game.

Install

In Claude Code:

/plugin marketplace add GhazaGG/Game-Sound-Effect-for-Claude
/plugin install game-sfx@game-sfx

Then just ask: "make a coin pickup sound for my platformer, with 4 variants." Output is game-ready WAV. Read the full docs or leave a ⭐ if it saved you from raw beeps.
